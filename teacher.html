1. Структура

Загружаю каталог…

Короткая ссылка записи — ?e=папка/имя. QR не меняется, даже если потом поправить стиль в каталоге. QR-лист папки

Как устроен каталог
  1. Папки лежат в structures/. Название — в _folder.json.
  2. Настройки и записи без файла (COD, RCSB, PubChem, CCDC) — в _entries.json этой папки.
  3. Кнопка «Сохранить в каталог» готовит JSON и открывает редактор GitHub. Сайт статический, сам он файл не записывает.

Файл скачивается каждым телефоном напрямую с files.rcsb.org — 30 учеников одновременно для них не нагрузка.

3D-модели малых молекул из PubChem (ethanol, benzene, glucose, cholesterol…).

CIF скачивается с crystallography.net. У COD нет CORS, поэтому браузер ходит через прокси (локально это работает сразу; на GitHub Pages домен нужно один раз разрешить на corsfix.com). Для урока надёжнее сохранить CIF в каталог.

Карточка в Access Structures ↗

CCDC не отдаёт CIF без согласия с условиями (имя, почта, организация) и не пускает чужие сайты. Скачайте файл там и перетащите его сюда. Маленький CIF встроится в ссылку, большой — предложим загрузить в репозиторий. Номер сохранится в каталоге как ссылка на карточку.
Перетащите CIF, скачанный с CCDC

Сервер должен разрешать загрузку с других сайтов (CORS). Подходят raw.githubusercontent.com, gist, files.rcsb.org. Google Диск и Яндекс Диск — не подходят.

Перетащите сюда файл .pdb / .cif / .sdf / .mol2 / .xyz
или нажмите, чтобы выбрать

2. Как увидят ученики

Два пальца: щипок — масштаб, сдвиг — панорама. На компьютере панорама — правая кнопка или Ctrl+перетаскивание.

Поверните и приблизьте молекулу как нужно, затем нажмите «Запомнить текущий ракурс». Два пальца сдвигают вид и не выбирают атом.

Выберите режим и нажимайте атомы в предпросмотре.
