Доступ к GitHub (токен)
Сайт статический: сам записать файлы он не может. Кнопка «Сохранить на GitHub» делает коммит в репозиторий через GitHub API от вашего имени. Для этого нужен fine-grained токен:
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → только этот репозиторий.
  3. Permissions → Repository permissions → Contents: Read and write (Metadata: Read-only добавится сам). Больше ничего не нужно.
  4. Срок действия — сколько удобно (например, до конца учебного года).
Токен — это ключ от репозитория. Он хранится только в этом браузере: по умолчанию до закрытия вкладки (sessionStorage); с галочкой «Запомнить» — на этом устройстве (localStorage). В адрес страницы и в файлы сайта он не попадает. Не ставьте галочку на чужом или общем компьютере. Адрес этой страницы — не защита: её код открыт, защищает только токен. Если токен утёк — удалите его на GitHub (Revoke), сайт продолжит работать.

Ссылки для учеников

Ученики видят только заполненные рисунки. Из этих страниц нельзя выйти в общий каталог.

Загрузить файлы по именам

Номер = глава.рисунок.часть, например 5.11.2 → Рис. 5.11, часть 2 (разделитель — точка, дефис или подчёркивание). Задачи — с ! в начале: !5.3.1 → Задача 5.3, «Условие»; со словом «ответ» — в «Ответ». Номер берётся из имени файла или из заголовка структуры в .mae (Title в Maestro, например «Рис 5-11-2 Cu»; если там пусто — из имени записи). Разные номера у структур одного .mae — каждая структура ляжет на своё место отдельным файлом. Части одного рисунка становятся вариантами для переключения. Сначала проверьте таблицу, потом «Разложить». Форматы: .mae, .maegz, PDB, SDF, MOL, MOL2, XYZ, CIF.

Как это работает
  • Файлы Maestro (.mae, .maegz) открываются со сценой: цвета атомов, представление (каркас, трубки, шарики и палочки, CPK), скрытые атомы, подписи и связи нулевого порядка (пунктиром). Ученик может переключить «Стиль/Цвета из Maestro» ↔ стандартные в меню «Вид».
  • Все названия, подписи и списки структур хранятся в structures/_book/book.json, файлы структур — в structures/_book/files/.
  • «Сохранить на GitHub» отправляет один коммит: книгу и все новые файлы. Через 1–2 минуты GitHub Actions опубликует сайт.
  • Несколько структур в рисунке — у ученика появится меню «Выбор структуры». «Параметры» дают несколько рядов кнопок, как у краун-эфиров.
  • «Готовый набор» — путь к файлу *.set.json от папки structures, например _supra/crown/complexes.
  • Источник можно указать без файла: id:1CRN (PDB), cid:2519 (PubChem), cod:1000041, e:Белки/1crn (запись каталога), pdb:structures/…/файл.sdf.
  • Без токена: «Скачать JSON» → загрузите файл на GitHub в structures/_book/book.json вручную (Add file → Upload files).
