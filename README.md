# 3D-просмотрщик молекул по QR-коду (PDB, CIF, SDF, MOL2, XYZ)

Статический сайт для GitHub Pages. Учитель кладёт структуру в репозиторий (или берёт её по PDB ID / из PubChem), получает ссылку и QR-код. Ученики сканируют QR, и у каждого на телефоне открывается своя 3D-модель: её можно вращать, приближать, менять стиль и сохранять снимок. Сервер не нужен. Каждый телефон сам скачивает файл с GitHub Pages и рисует его у себя, поэтому 30 учеников одновременно ничем не мешают друг другу.

- `index.html` — просмотрщик для учеников (полноэкранный, рассчитан на телефон). Если открыть его без параметров, покажется каталог структур.
- `teacher.html` — страница учителя: выбор структуры, настройка вида, ссылка, QR-код, скачивание QR в PNG, показ QR на проекторе.

Внутри используется [3Dmol.js](https://3dmol.org) 2.5.5 (лёгкий, хорошо работает с жестами на iOS и Android), [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) и [pako](https://github.com/nodeca/pako). Копии библиотек лежат в `assets/vendor/`. Если они вдруг не загрузятся, страница подтянет их с CDN jsDelivr.

## Как опубликовать на GitHub Pages (один раз, примерно 5 минут)

1. Зарегистрируйтесь на <https://github.com> или войдите в аккаунт.
2. Нажмите **+ → New repository**. Название, например, `pdb-viewer`. Тип: **Public** (на бесплатном тарифе Pages работает только для публичных репозиториев). Нажмите **Create repository**.
3. Загрузите файлы:
   - **Через браузер:** на странице нового репозитория нажмите **uploading an existing file**, перетащите *содержимое* папки `pdb-viewer` (файлы `index.html`, `teacher.html`, `README.md`, `.nojekyll` и папки `assets`, `structures`, `tools`, `.github`), затем нажмите **Commit changes**.
     ⚠ Скрытые папки и файлы (`.github`, `.nojekyll`) браузер иногда не перетаскивает. Если папка `.github` не загрузилась, создайте файл вручную: **Add file → Create new file**, имя `.github/workflows/pages.yml`, и вставьте в него содержимое этого файла из архива.
   - **Через git:**
     ```bash
     cd pdb-viewer
     git init -b main
     git add .
     git commit -m "3D-просмотрщик"
     git remote add origin https://github.com/ВАШ_ЛОГИН/pdb-viewer.git
     git push -u origin main
     ```
4. В репозитории откройте **Settings → Pages**. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
5. Откройте вкладку **Actions**. Там будет задача «Публикация на GitHub Pages». Если она не запустилась сама, выберите её и нажмите **Run workflow**. Когда появится зелёная галочка (около минуты), сайт заработает по адресу:
   - просмотрщик: `https://ВАШ_ЛОГИН.github.io/pdb-viewer/`
   - страница учителя: `https://ВАШ_ЛОГИН.github.io/pdb-viewer/teacher.html`

> Можно обойтись без Actions: **Settings → Pages → Source: Deploy from a branch → main / (root)**. В этом случае `structures/index.json`, то есть список структур, придётся обновлять самому (см. ниже).

## Как добавить свою структуру

1. На GitHub откройте папку `structures` и нажмите **Add file → Upload files**.
2. Перетащите файл (`.pdb`, `.cif`, `.sdf`, `.mol`, `.mol2`, `.xyz`, `.pqr`, `.gro`). Имя лучше давать латиницей без пробелов, например `aspirin.sdf`. Регистр букв имеет значение.
3. Нажмите **Commit changes**. Через 1–2 минуты GitHub Actions сам добавит файл в `structures/index.json` и обновит сайт.
4. Откройте `teacher.html`, обновите страницу. Файл появится в списке «Из репозитория».

Название и описание, которые видят ученики, можно поправить в `structures/index.json`: откройте файл на GitHub и нажмите ✏️. Пример записи:

```json
{
  "file": "1crn.pdb",
  "title": "Крамбин (1CRN)",
  "description": "Небольшой белок из семян крамбе",
  "params": { "style": "cartoon", "color": "ss" }
}
```

`params` задаёт вид по умолчанию для этой структуры. Ключи те же, что у параметров ссылки ниже.
Если сайт публикуется без Actions, после добавления файла выполните на компьютере `node tools/build-index.mjs` (нужен Node.js) или просто допишите запись в `index.json` вручную.

## Как провести урок

1. Откройте `https://ВАШ_ЛОГИН.github.io/pdb-viewer/teacher.html`.
2. Выберите структуру: из репозитория, по **PDB ID** (банк RCSB, например `1CRN`, `4HHB`, `1BNA`), из **PubChem** (по английскому названию: `glucose`, `aspirin`) или по прямой ссылке.
3. Настройте вид: стиль, цвет, подписи, фон, вращение, поверхность. Поверните молекулу как нужно и нажмите **📌 Запомнить текущий ракурс**.
4. Включите **Запретить менять стиль**, если хотите, чтобы все ученики видели одно и то же. Вращать и приближать модель они всё равно смогут.
5. Нажмите **🖥 QR на весь экран** и покажите QR на проекторе, или нажмите **⬇ QR в PNG** и вставьте картинку в презентацию или на доску. Ссылку можно отправить в чат.

### Свой файл без загрузки на GitHub

На вкладке **«Свой файл»** можно перетащить файл с компьютера. Если после сжатия он помещается в QR-код (примерно до 2,9 КБ, а это малые молекулы до ~100–150 атомов), его данные встраиваются прямо в ссылку, после `#`. Тогда ничего загружать не нужно. Белки и ДНК обычно в ссылку не влезают. Страница сама это определит и подскажет загрузить файл в `structures/`.

## Параметры ссылки (для продвинутых)

| Параметр | Значения | Что делает |
|---|---|---|
| `pdb=` | `structures/1crn.pdb` | файл из репозитория (относительный путь) |
| `id=` | `1CRN` | структура из банка RCSB PDB |
| `cid=` | `2519` | малая молекула из PubChem (3D) |
| `url=` | прямая ссылка | файл с другого сайта (нужен CORS, подходит `raw.githubusercontent.com`) |
| `style=` | `auto`, `cartoon`, `stick`, `ballstick`, `sphere`, `line` | стиль |
| `color=` | `auto`, `element`, `chain`, `spectrum`, `ss` | цвет: по элементам, по цепям, радуга, вторичная структура |
| `labels=` | `off`, `atoms`, `res` | подписи атомов или аминокислот |
| `bg=` | `ffffff`, `111827`… | цвет фона (hex без #) |
| `spin=1` | | вращение при открытии |
| `surface=1` | `1`, `vdw`, `sas` | полупрозрачная поверхность (`sop=0.6` задаёт прозрачность) |
| `water=1` | | показать молекулы воды (по умолчанию скрыты) |
| `h=0` | | скрыть атомы водорода |
| `lock=1` | | убрать у учеников кнопку «Стиль» |
| `title=` | текст | заголовок вместо названия из файла |
| `view=` | числа через `_` | ракурс (кнопка «Запомнить ракурс» ставит его сама) |
| `fmt=` | `pdb`, `cif`, `sdf`, `mol2`, `xyz` | формат, если по расширению файла его не понять |

Пример: `https://ВАШ_ЛОГИН.github.io/pdb-viewer/?id=4HHB&style=cartoon&color=chain&spin=1`

## Что умеет просмотрщик у ученика

- вращение одним пальцем, приближение и сдвиг двумя пальцами (на компьютере работает мышь);
- нажатие на атом показывает элемент, аминокислоту и цепь;
- кнопки: **Стиль** (стиль, цвет, подписи, поверхность, тёмный фон, вода, водороды), **Сброс** вида, **Вращать**, **Фото** (PNG; на телефоне открывается меню «Поделиться / Сохранить изображение»), **Экран** (полноэкранный режим), **i** (название, описание, метод, разрешение, число атомов, ссылка на RCSB).

## Ограничения

- На iPhone в Safari нет полноэкранного режима для сайтов, поэтому кнопка «Экран» там скрыта. Вместо этого можно выбрать «Поделиться → На экран Домой».
- Очень большие структуры (больше ~50–100 тыс. атомов, например рибосома) на слабых телефонах открываются медленно. Поверхность для больших белков считается несколько секунд.
- Из NMR-файлов с несколькими моделями показывается только первая модель.
- `url=` работает, только если сайт-источник разрешает загрузку с других сайтов (CORS). Google Диск и Яндекс Диск этого не разрешают.
- Нужен интернет, хотя бы для первого открытия страницы.

## Структура репозитория

```
index.html                  просмотрщик (ученик)
teacher.html                страница учителя (ссылка + QR)
assets/core.js              общий код: загрузка, стили, параметры, сжатие
assets/vendor/              3Dmol.js, qrcode-generator, pako
structures/                 файлы структур + index.json (каталог)
tools/build-index.mjs       пересборка structures/index.json
tools/test-mobile.mjs       автотест в headless Chrome (для разработчика, необязателен)
.github/workflows/pages.yml публикация на Pages + автообновление index.json
.nojekyll                   отключает обработку Jekyll
```

Примеры в `structures/`: крамбин 1CRN и B-ДНК 1BNA (RCSB PDB), кофеин (PubChem CID 2519).
