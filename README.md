# 3D-просмотрщик молекул по QR-коду

Статический сайт для GitHub Pages. Учитель собирает каталог структур (файл в репозитории, PDB, PubChem, COD или CIF из CCDC), получает короткую ссылку и QR-код. Ученик открывает модель на телефоне: её можно вращать, сдвигать двумя пальцами, менять стиль, смотреть заряды и контакты. Сервер не нужен — каждый телефон рисует структуру сам.

- `index.html` — просмотрщик для учеников. Без параметров открывается дерево каталога.
- `teacher.html` — страница учителя: каталог, COD/CCDC, вид, ссылка, QR.
- `qr.html` — лист QR-кодов на всю папку, для печати.
- `book.html` — учебник «Супрамолекулярная химия» для учеников: главы, «Материалы главы» и «Задачи и тесты».
- `redaktor-uchebnika-q7m4.html` — редактор учебника для учителя (ссылок на него на сайте нет).
- `assets/core.js` — загрузка, стили, каталог, жесты.
- `assets/chem.js` — водороды, заряды, невалентные контакты.
- `structures/` — дерево папок, `index.json`, файлы структур.

Внутри: [3Dmol.js](https://3dmol.org) 2.5.5, [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator), [pako](https://github.com/nodeca/pako). Копии лежат в `assets/vendor/`, при сбое страница берёт их с jsDelivr.

## Как опубликовать на GitHub Pages

1. Репозиторий должен быть **публичным**.
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. При каждом пуше в `main` workflow `.github/workflows/pages.yml` заново собирает `structures/index.json` и публикует сайт.
4. Адреса: `https://ВАШ_ЛОГИН.github.io/pdb-viewer/` и `.../teacher.html`.

Живой пример этого репозитория: <https://cyril-ver-mar.github.io/pdb-viewer/>.

## Каталог с папками

`structures/` может содержать вложенные папки, например `structures/Белки/Ферменты/`.

В каждой папке необязательно лежат два файла:

- `_folder.json` — название, описание и порядок папки:

```json
{ "title": "Белки", "description": "Белковые молекулы", "order": 1 }
```

- `_entries.json` — записи этой папки. У записи есть короткий `slug`, заголовок, описание, источник и сохранённый вид:

```json
{
  "slug": "1crn",
  "title": "Крамбин (1CRN)",
  "description": "Небольшой белок",
  "source": { "type": "file", "file": "1crn.pdb" },
  "params": { "style": "cartoon", "color": "ss" }
}
```

Источник (`source.type`):

| type | поля | откуда берётся модель |
|---|---|---|
| `file` | `file` | файл в этой же папке |
| `rcsb` | `id` | RCSB PDB, файл не хранится |
| `pubchem` | `cid` | 3D-SDF из PubChem |
| `cod` | `id`, необязательно `file` | Crystallography Open Database; если указан `file`, ученики читают CIF из репозитория |
| `ccdc` | `id`, обычно ещё `file` | номер или рефкод Кембриджской базы; сам CIF CCDC по ссылке не отдаёт |

Запись без файла — виртуальная: в каталоге есть только номер и настройки. Так можно копить базу, не загружая большие файлы. `node tools/build-index.mjs` (его же запускает Actions) собирает из этих файлов дерево `structures/index.json`. Файл, которого нет в `_entries.json`, добавляется сам.

Короткая ссылка записи: `?e=Белки/1crn`. В QR попадает только она, поэтому код не меняется, когда учитель потом поправит стиль в `_entries.json`. Старые ссылки `?pdb=structures/1crn.pdb`, `?pdb=structures/1bna.pdb` и `?pdb=structures/caffeine.sdf` продолжают открываться: карта лежит в `structures/_legacy.json`.

На телефоне без параметров ученик листает папки, ищет по названию и может открыть «QR-лист» текущей папки. Страница `qr.html?folder=Кристаллы` печатает сетку QR с подписями (кнопка «Печать»).

### Как учитель сохраняет вид

Кнопки «записать на сервер» нет. «Сохранить в каталог» на `teacher.html` собирает готовый `_entries.json`, копирует его в буфер и открывает редактор GitHub:

- изменить существующий файл: `github.com/cyril-ver-mar/pdb-viewer/edit/main/structures/<папка>/_entries.json`
- создать новый: `.../new/main/structures/<папка>?filename=_entries.json`
- загрузить CIF: `.../upload/main/structures/<папка>`

Дальше Commit changes. Через одну-две минуты Actions обновит каталог.

## COD

Ссылка `?cod=1000041` открывает CIF `https://www.crystallography.net/cod/1000041.cif`. У сайта COD **нет заголовка CORS**, поэтому браузер не может скачать файл напрямую. Страница просит тот же адрес через прокси `https://proxy.corsfix.com/` (на localhost прокси пускает без ключа). На GitHub Pages Corsfix отвечает 403, пока домен сайта один раз не добавлен в кабинете <https://corsfix.com> (бесплатно). Пока домена нет, работают структуры, чей CIF уже лежит в репозитории: `?cod=1000041` на опубликованном сайте сначала ищет файл в каталоге.

На странице учителя есть номер COD и поиск по названию или формуле (`result?format=json&text=...`). Если поиск из браузера не открылся, остаётся ссылка на сайт COD.

Кристалл показывается шариками и палочками, с рамкой элементарной ячейки. Повтор ячейки: `rep=2x2x2` (ещё `3x3x3`). Симметрия CIF разворачивается в полную ячейку до отрисовки, затем 3Dmol вызывает `addUnitCell` и `replicateUnitCell`.

Проверенные номера:

| вещество | COD | что в файле |
|---|---|---|
| хлорид натрия, галит | 1000041 | NaCl, Fm-3m, a = 5,62 Å |
| алмаз | 9008564 | C, Fd-3m, a = 3,57 Å |
| графит | 9008569 | C, P6₃mc, a = 2,46 Å, c = 6,70 Å |
| α-кварц | 1011097 | SiO₂, «Quartz low», P3₁21 |

## CCDC / CSD

Открытого CORS-адреса с CIF нет. Страница Access Structures по `?ccdc=710857` или `?ccdc=CAFINE` открывает поиск `https://www.ccdc.cam.ac.uk/structures/Search?Ccdcid=<номер>&DatabaseToSearch=Published` и получает HTML, не CIF. Скачивание включается только после согласия с условиями: имя, почта, организация. Поэтому просмотрщик **не подставляет структуру CCDC сам**.

Что можно сделать: скачать CIF на сайте CCDC, перетащить его на вкладку «CCDC» страницы учителя (маленький файл встроится в ссылку, большой — в репозиторий) и сохранить номер в каталоге. У записи будет ссылка на карточку Access Structures.

## Жесты

Один палец или левая кнопка мыши — вращение. Щипок двумя пальцами — масштаб. Параллельный сдвиг двумя пальцами — панорама; щипок и сдвиг можно делать одновременно, как на карте. На компьютере панорама — правая кнопка или Ctrl+перетаскивание, масштаб — колесо.

## Водороды, заряды, контакты, поверхности

Всё считается в браузере (`assets/chem.js`), без RDKit и OpenChemLib: эти библиотеки слишком тяжёлые для класса на мобильном интернете. Большие структуры предупреждают и ограничиваются.

- `addh=1` — недостающие водороды. Гибридизация и число H берутся из связей и порядка связи; если порядков в файле нет, они оцениваются по длинам и ароматическим циклам. Белки и нуклеиновые кислоты — по шаблону остатка (N–H остова в плоскости пептида, NH₃⁺ на N-конце, тетраэдрические CH₃ со смещением 60°, ароматические H фенилаланина/тирозина/триптофана/гистидина в плоскости кольца, гуанидин аргинина и амиды Asn/Gln плоские, вода). Длины: C–H 1,09, N–H 1,01, O–H 0,96, S–H 1,34 Å. Угол sp³ — 109,5°, sp² — 120° в плоскости соседей, sp — 180°. OH/SH с одним соседом ставится под ~109° и по возможности к акцептору водородной связи. Уже присутствующие H не дублируются. В кристалле сосед за гранью ячейки тоже считается (у кварца Si и O уже четырёх- и двухкоординированы, лишние H не ставятся). Каждый новый H явно связан с родителем (`bonds` и `bondOrder`), поэтому в режимах «палочки» и «шарики и палочки» связь видна, в том числе после повтора кристаллической ячейки.
- `color=charge` — частичный заряд. До ~400 тяжёлых атомов и не белок: метод Гастайгера (PEOE, 6 итераций). Белок: упрощённый шаблон остатков в духе AMBER (остов, Asp/Glu, Lys/Arg, ионы). Это качественная раскраска, не квантовый расчёт. Шкала: **синий — отрицательный, белый — ноль, красный — положительный**. Значение пишется при нажатии на атом. Подпись метода видна в легенде и в окне «i».
- `color=hp` — гидрофобность по шкале Кайт–Дулитл для остатка (оранжевый — гидрофобный, голубой — гидрофильный).
- `ix=hb,xb,salt,pi,cat,hp,vdw` — пунктир контактов и список. Критерии приближённые, для урока:
  - **hb** — водородная связь: при наличии H расстояние H···A 1,4–2,6 Å и угол D–H–A ≥ 120°; без H — N/O···N/O 2,5–3,3 Å;
  - **xb** — галогенная: C–Cl/Br/I···N/O/S короче суммы ван-дер-ваальсовых радиусов, угол при галогене ≥ 140°;
  - **salt** — ионная пара ближе 4 Å (Lys, Arg, His, Asp, Glu, Na⁺/K⁺/Mg²⁺/Ca²⁺ и галогенид-ионы);
  - **pi** — π–π: центры колец 3,2–6 Å, плоскость или T-форма;
  - **cat** — катион–π, 3–6 Å до центра кольца;
  - **hp** — контакт C···C 3–4,2 Å между разными остатками;
  - **vdw** — расстояние меньше суммы ван-дер-ваальсовых радиусов на 0,15 Å и больше, чем ковалентная связь.
  Соседи через одну-две связи не считаются. Для кристалла после повтора ячейки контакты ищутся и между копиями. `ixsel=all|chain|ligand|res`, для остатка ещё `ixch`, `ixres`, `ixrad`. В списке не больше 250 строк.
- Поверхность: `surface=vdw` (Ван-дер-Ваальс), `sas` (доступная растворителю), `ses` (молекулярная, в 3Dmol это solvent-excluded / MS). Прозрачность — `sop`. Цвет поверхности — `scol=element|charge|hp|chain`. Область — `ssel=all|ligand|chain|res` и при необходимости `sch`, `sres`.

Эти параметры пишутся в ссылку и в `params` записи каталога, поэтому QR их воспроизводит. Для записи каталога надёжнее короткая ссылка `?e=...`: вид хранится в `_entries.json`, а не в длинном QR.

## Измерения

Кнопка «Измерения» есть у ученика и в предпросмотре учителя.

- **Расстояние** — два атома, длина в ангстремах, пунктир и подпись посередине.
- **Угол** — три атома, градусы при втором.
- **Двугранный угол** — четыре атома по порядку связи, знак от −180° до 180°.

Выбранные атомы подсвечиваются и нумеруются. Вращение и сдвиг (в том числе двумя пальцами) атом не выбирают: короткое нажатие без движения — выбор. Список можно править: удалить строку, «Назад», «Отмена», «Очистить все». После смены стиля или поверхности линии остаются на тех же атомах. Номера в `meas=` зависят от `addh` и `rep`: если включить водороды или другой повтор ячейки, старые номера могут указывать на другие атомы. В каталог измерение попадает вместе с остальными `params`.

Пример: `https://cyril-ver-mar.github.io/pdb-viewer/?cod=1000041&rep=2x2x2`

Примеры в каталоге: крамбин и гемоглобин (гемоглобин виртуальный, из RCSB), B-ДНК, кофеин, четыре кристалла COD.

## Ограничения

- Полноэкранный режим на iPhone в Safari недоступен.
- Очень большие структуры (десятки тысяч атомов) на слабом телефоне открываются медленно; водороды и контакты для них отключаются или сокращаются.
- Заряды Гастайгера и шаблон AMBER — учебная раскраска, не энергия электростатики.
- Контакты зависят от того, есть ли водороды, и не заменяют расчёт в специализированной программе.
- `url=` работает только если чужой сайт разрешает CORS.
- Нужен интернет, хотя бы для первого открытия.

## Наборы структур (несколько структур в одной ссылке)

Ссылка открывает просмотрщик с отдельным меню **«Выбор структуры»** (на телефоне — шторка под молекулой, на компьютере — панель справа).

- **Краун-эфиры** (`structures/_supra/crown/`): `complexes.set.json` — размер цикла (12-краун-4 … 21-краун-7), «показать комплекс», ион Li⁺…Cs⁺, 1 : 1 или сэндвич 2 : 1; `annel.set.json` — бензо/циклогексано, моно…гекса и эталон 18-краун-6 · K⁺. Ссылки: `?e=Супрамолекулярная химия/Краун-эфиры/complexes` (и `/annel`) или коротко `?set=_supra/crown/complexes&pick=size:6,cx:1,metal:K,ratio:1`.
- Исходные файлы учителя — `original/`, выровненные — `complexes/`, `annel/`. Пересборка: `python3 tools/align_crowns.py` (нужен numpy). Скрипт переносит каждую структуру целиком только поворотом и сдвигом (Кабш по атомам макроцикла: кольцевые O и C), центр цикла — в начало координат, нормаль цикла — вдоль z, ион эталона N-K — сверху. Отчёт — `align-report.json`.
- **Набор учителя**: на `teacher.html` блок «Несколько структур в одной ссылке» — откройте структуру, «Добавить в набор», подпишите. Ссылка `#ms=…` (список источников, сжатый deflate), «Сохранить в каталог» пишет запись `{"type": "set", "items": [{"t": "подпись", "s": "e:папка/запись"}]}`. Источники: `e:` запись каталога, `pdb:` путь в репозитории, `file:` файл в папке записи, `id:` PDB, `cod:`, `cid:`, `url:`, `d:` встроенный файл.
- Проверка: `node tools/test-sets.mjs` (iPhone 13 WebKit, Pixel 7, 1280×800).


## Учебник: главы, рисунки, задачи

Учебник «Супрамолекулярная химия» лежит в `structures/_book/book.json`: 5 глав, в каждой «Материалы главы» (рисунки `Рис. N.k`) и «Задачи и тесты» (`Задача N.k`). Файлы структур — в `structures/_book/files/ch<глава>/<id рисунка>/`. Пустой файл с нужным числом рисунков делает `node tools/make-book.mjs` (существующий не трогает).

Ссылки для учеников (выйти из них в общий каталог нельзя):

- весь учебник: `book.html`;
- глава: `book.html?ch=4`; вкладка задач: `book.html?ch=4&tab=t`;
- один рисунок (для QR): `index.html?fig=4m2`; задача: `index.html?fig=4t1`.

Ученики видят только заполненные рисунки (есть хотя бы одна структура и не стоит «Скрыть от учеников»). Если в рисунке несколько структур, открывается меню «Выбор структуры»: либо список, либо несколько рядов параметров (как у краун-эфиров), либо готовый набор `*.set.json`. В задаче есть кнопки «Условие» и «Ответ»; ответ показывается только после нажатия (параметр `pick=part:a` в ссылке не действует).

Просмотрщик, открытый прямой ссылкой (`?fig=`, `?e=`, `?set=`, `?pdb=`, `?id=` …), не показывает «← Каталог», «Разделы» и «Все структуры». Карточки самого каталога добавляют к ссылке `&nav=1` — тогда кнопки есть. Рисунок, открытый со страницы главы, получает `&bk=ch=4&tab=t` и кнопку «←» обратно в эту главу, не дальше. В общем каталоге учебник — подпапка «Учебник „Супрамолекулярная химия“» в папке «Супрамолекулярная химия» (поле `"book"` в её `_folder.json`): главы → «Материалы главы» / «Задачи и тесты» → готовые рисунки. Эти папки собирает `tools/build-index.mjs` из `book.json` (записи типа `fig`); на странице учителя по ним строятся ссылка `index.html?fig=…` и QR.

**Какие большие разделы видят ученики.** Список шести разделов — в `assets/sections.js`; у каждого поле `"hidden"`. Сейчас ученикам видны только «Супрамолекулярная химия» и «Молекулярные машины»; «Физика взаимодействий», «Симметрия», «Уравнения состояния» и «Физика кристаллов» скрыты (`"hidden": true`). Скрытый раздел пропадает из каталога и меню «Разделы», но его страница и старые ссылки работают. Вернуть: на странице учителя блок «Разделы в каталоге учеников» — поставить галочку и «Сохранить на GitHub» (токен как в редакторе учебника), либо поменять `"hidden": true` на `false` в файле.

### Редактор

`redaktor-uchebnika-q7m4.html`: все рисунки, в том числе пустые; переименование, подписи, текст условия, добавление рисунков, порядок (↑ ↓), удаление, загрузка файлов PDB/SDF/MOL/XYZ/CIF, источники без файла (`id:1CRN`, `cid:2519`, `cod:…`, `e:папка/запись`), параметры переключения, ссылки и QR.

«Сохранить на GitHub» делает один коммит (Git Data API): `book.json` и новые файлы; убранные из учебника файлы удаляются. Затем Actions публикует сайт (1–2 минуты). Нужен **fine-grained** токен GitHub: Repository access → Only select repositories → этот репозиторий; Permissions → Contents: **Read and write**. Токен хранится только в браузере (sessionStorage, с галочкой «Запомнить» — localStorage), в адрес и в файлы не попадает. Код редактора открыт, поэтому защищает только токен, а не адрес страницы. Без токена: «Скачать JSON» и загрузить файл в `structures/_book/` через веб-интерфейс GitHub.

Тест: `BASE=http://127.0.0.1:18431/ node tools/test-book.mjs` (GitHub API в тесте поддельный).

### Файлы по именам и Maestro (.mae)

Имя файла задаёт место: `глава.рисунок.часть` (разделитель `.`, `-`, `_` или пробел), например `5.11.2.mae` → Рис. 5.11 (`5m11`), вариант «Часть 2». Задачи — с `!` в начале: `!5.3.1.mae` → Задача 5.3, «Условие»; со словом «ответ»/«answer» в имени — «Ответ». Части одного рисунка — варианты переключения; несколько структур (CT) в одном .mae — тоже (`файл.mae#ct=2`). Заполненное не удаляется, тот же файл заменяет сам себя (подписи из редактора сохраняются), готовые наборы (`set`) не трогаются. Правило — `assets/book-place.js`: в редакторе блок «Загрузить файлы по именам», на машине — `node tools/import-book-files.mjs файлы…` (или `путь=5-11-2.mae`, `--merge`, `--dry`).

Номер можно брать и из заголовка структуры в .mae (`s_m_title`, если пусто — `s_m_entry_name`): в редакторе переключатель «Номер из: имя файла / заголовок в .mae» плюс выбор для каждой строки таблицы, на машине — `--from-title`. Заголовок разбирается так же (`Рис 5-11-2 Cu`, `!5.4.1 ответ`). Если у структур одного .mae разные номера, каждая ложится на своё место отдельным файлом (с той же шапкой). Нет номера в заголовке — строка красная, берётся номер из имени файла. Сначала показывается таблица (файл, заголовок, откуда номер, куда, занято ли), потом «Разложить».

Maestro (`.mae`, `.maegz`) разбирает `assets/mae.js` прямо в браузере — в репозитории лежит исходный файл. Сохраняется сцена: цвет каждого атома (`s_m_color_rgb`, иначе номер `i_m_color`), представление атома (`i_m_representation`: нет / кружок / CPK / шарик) и половин связей (`i_m_from_rep`/`i_m_to_rep`: каркас / трубка / палочка), скрытые атомы (`i_m_visibility`), подписи (`s_m_label_format`, `%UT` и др.), формальные заряды, связи нулевого порядка — пунктиром в цветах атомов. В меню «Вид» — «Стиль из Maestro / стандартный» и «Цвета из Maestro / стандартные» (параметры ссылки `msc=0`, `mcol=0`). Не переносятся: ракурс камеры Maestro, поверхности, ленты белков, толщина «тонкой/толстой трубки», шрифты подписей. Тест: `node tools/test-mae.mjs` (тестовый файл `structures/_test/mae/test-scene.mae`, его делает `tools/make-mae-fixture.py`).
